# Курсовая работа №1

## Описание:

### Модуль main.py
Предназначен для вывода результатов работы функций остальных модулей.

### Модуль views.py
#### Функция main
Основная функция для генерации JSON-ответов (результат функции main модуля views.py).
Данные для анализа и вывода на веб-страницах — это данные с начала месяца, на который выпадает входящая дата, по входящую дату.
Валюты и акции для отображения на веб-страницах задаются в отдельном файле пользовательских настроек user_settings.json.
```
Пример:

{
  "user_currencies": ["USD", "EUR"],
  "user_stocks": ["AAPL", "AMZN", "GOOGL", "MSFT", "TSLA"]
}
```
### Модуль utils.py (вспомогательные функции для views.py)
#### Функция greeting
Выдает сообщение приветствия в формате «Доброе утро» / «Добрый день» / «Добрый вечер» / «Доброй ночи»
в зависимости от текущего времени суток.
#### Функция reader_excel
Принимает путь к Excel-файлу и возвращает данные в DataFrame.
#### Функция current_month_operations
Принимает данные операций и возвращает только те, которые выполнены в месяце входящей даты до дня входящей даты.
#### Функция cards_info
Принимает данные операций и выводит:
* последние 4 цифры карты;
* общая сумма расходов;
* кешбэк (1 рубль на каждые 100 рублей - в процентах).
#### Функция top_5_operations
Выводит топ-5 операций по платежам.
#### Функция get_user_settings
Извлекает запрашиваемые данные из файла 'user_settings.json'.
#### Функция currency_rates
Выводит список словарей с курсами валют пользователя из API ЦБ РФ.
#### Функция stock_prices
Выводит стоимость акций.

### Модуль services.py
#### Функция main (основная)
Функция позволяет проанализировать, какие категории были наиболее выгодными для выбора в качестве категорий повышенного кешбэка.

Входные параметры функции:
* data — данные с транзакциями;
* year — год, за который проводится анализ;
* month — месяц, за который проводится анализ.

На выходе — JSON с анализом, сколько на каждой категории можно заработать кешбэка в указанном месяце года.
Выходные параметры JSON с анализом, сколько на каждой категории можно заработать кешбэка (результат функции main модуля services.py).

Формат выходных данных:
```
{
    "Категория 1": 1000,
    "Категория 2": 2000,
    "Категория 3": 500
}
```
#### Функция operations_filtered_by_month_and_year (вспомогательная)
Фильтрует операции по месяцу и году.
#### Функция cashback_info (вспомогательная)
Выдает количество кэшбэка по категориям.

### Модуль reports.py
#### Функция spending_by_category
Функция возвращает траты по заданной категории за последние три месяца (от переданной даты). Формат входной даты '%d.%m.%Y %H:%M:%S'. Если дата не передана, то берется текущая дата.
#### Декоратор decorator_with_args
Декоратор записывает в файл результат, который возвращает функция, формирующая отчет.
Декоратор с параметром — принимает имя файла в качестве параметра.
